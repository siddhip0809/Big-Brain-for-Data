# Sources

This folder holds raw material that facts in the brain were derived from —
pasted article text, notes from a call, a copied spreadsheet excerpt, etc.

Nothing needs to go here manually. When you give Claude information to add
to the brain, Claude will save the raw material here (e.g.
`2026-09-04-example-datacentral-notes.md`) and reference it from the
relevant node or relationship's `sources` field, so every fact can be
traced back to where it came from.
